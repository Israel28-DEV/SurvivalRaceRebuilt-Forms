## 🔧 Basic Modding

To mod the game you'll need Unity **2022.3.24f1** installed.

- Car meshes are stored in `Assets/Mesh/`
- Materials are in `Assets/Material/`
- Scripts are in `Assets/Scripts/`

Replace or add assets and rebuild the project in Unity 2022.3.24f1.

---

## 🚗 Adding a Custom Car

1. Import your car mesh (`.fbx` or `.glb`) into `Assets/Mesh/`
2. Create a new material in `Assets/Material/`
3. Duplicate the `PlayerCar` prefab in `Assets/Prefabs/`
4. Swap the mesh on the duplicate
5. Assign it in the **GameManager** Car Prefabs array
